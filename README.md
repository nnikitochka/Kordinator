> **Русский** | [English](README_EN.md)

**Kordinator — самостоятельный музыкальный бэкенд для собственной медиатеки.** Проект занимается сканированием локальных музыкальных каталогов, индексацией треков и метаданных, предоставляет REST API для поиска, потокового воспроизведения с транскодированием и управления плейлистами.

При наличии полноценной локальной музыкальной библиотеки Kordinator работает автономно — без подключения к интернету и доступа к сторонним ресурсам. Подключение внешних источников не обязательно для работы; при подключении они служат только для дополнения локальных данных и не заменяют их.

---

## 📌 Статус проекта

Бэкенд находится в активной разработке - API и настройки постоянно меняются и на текущий момент проект не готов к полноценному размещению.
