# Сравнительная функциональная матрица (Feature Matrix)

Полное, детальное сопоставление функциональных возможностей **Airsonic Advanced** и **Navidrome**. В таблицах отсутствуют сокращения «и т.д.» — все спецификации, форматы и особенности выписаны исчерпывающе.

---

## 1. Типы медиаконтента

| Функция / Формат | Airsonic Advanced | Navidrome | Особенности реализации |
|---|---|---|---|
| **Музыка (Audio)** | **Поддерживается** | **Поддерживается** | Полная поддержка MP3, FLAC, Ogg Vorbis, Opus, AAC, M4A, ALAC, WAV, AIFF. |
| **DSD / DSF / DFF** | **Поддерживается** (через транскодирование ffmpeg) | **Поддерживается** (начиная с v0.64+: cap rate control, downsample в PCM 88.2/176.4 кГц) | Navidrome содержит тонкие твики для DSD: ограничение DSD rate, конвертация в PCM высокого разрешения по умолчанию. |
| **WavPack (.wv)** | **Поддерживается** (миграция `add-wavpack.xml`) | **Поддерживается** (через TagLib и FFmpeg) | Оба проекта поддерживают чтение тегов и воспроизведение. |
| **Трекерная музыка (MOD, XM, IT, S3M)** | **Поддерживается** (миграция `insert-mod-transcoding.xml` через openmpt/ffmpeg) | **Ограниченно** (только если распознается TagLib и поддерживается установленной сборкой ffmpeg) | Airsonic имеет готовые преднастроенные правила транскодирования для трекерных форматов. |
| **Видео (MP4, MKV, AVI, WebM)** | **Поддерживается** (`VideosController.kt`, `HlsRestController.kt`, `VideoPlayerRestController.kt`) | **Не поддерживается** (намеренно, возвращает `HTTP 410 Gone`) | Airsonic включает полноценный движок нарезки HLS-сегментов на лету (`hlsSegment`), поддержку субтитров (`CaptionsRestController.kt`) и встроенный видеоплеер. Navidrome считает видео нецелевым форматом. |
| **Аудиокниги (Audiobooks, .m4b)** | **Поддерживается** (тип `MediaType.AUDIOBOOK`, сохранение закладок через `BookmarksController.kt`) | **Поддерживается** (отдельная библиотека или тег `genre=Audiobook`, сохранение позиций воспроизведения) | Оба проекта корректно сохраняют прогресс прослушивания через Subsonic Bookmarks API. В Navidrome планируется нативная поддержка разбивки по главам M4B. |
| **Подкасты (Podcasts)** | **В процессе удаления** (`POODCAST_REMOVAL_PLAN.md`, миграция `drop-podcasts.xml`) | **Не поддерживается** (эндпоинты возвращают `HTTP 501 Not Implemented`) | Исторически Airsonic имел полноценный RSS-загрузчик эпизодов. Наш форк удалил таблицы подкастов из БД и изолировал эндпоинты в карантин для вывода из кодовой базы. Navidrome изначально отказался от реализации подкастов. |
| **Интернет-радио (Web Radio)** | **Удалено в версии 11.0** (миграция `drop-internet-radio.xml`) | **Поддерживается** (`radio.go`, таблица `radio`, CRUD через Subsonic API) | Navidrome поддерживает управление станциями интернет-радио через API (`getInternetRadioStations`, `createInternetRadioStation`, `updateInternetRadioStation`, `deleteInternetRadioStation`). В нашем форке Airsonic радио было вырезано для концентрации на локальной медиатеке. |

## 2. Воспроизведение и аудиодвижок

| Функция | Airsonic Advanced | Navidrome | Особенности реализации |
|---|---|---|---|
| **Воспроизведение без пауз (Gapless Playback)** | На стороне клиента (передача точных метаданных треков) | **Нативно поддерживается** (клиентский gapless + динамический патчинг заголовков FLAC `total_samples`) | Navidrome на лету модифицирует стрим FLAC, чтобы плееры не спотыкались на границах треков при транскодировании. |
| **ReplayGain (Выравнивание громкости)** | **Поддерживается** (чтение тегов `REPLAYGAIN_TRACK_GAIN` и `REPLAYGAIN_ALBUM_GAIN`) | **Поддерживается** (чтение тегов Track Gain, Track Peak, Album Gain, Album Peak через TagLib) | Navidrome сохраняет поля ReplayGain в таблице `media_file` (`replay_gain_track_gain`, `replay_gain_album_gain`) и отдает их клиентам в Subsonic API. |
| **Режим Jukebox (Звук на сервере)** | **Устаревший Java Sound удален** (`remove-java-jukebox.xml`); сохранен REST API (`JukeboxController.kt`) | **Полноценно поддерживается** (`core/playback/mpv`, управление демоном `mpv` через сокет/IPC) | Navidrome умеет напрямую управлять локальным плеером MPV на сервере, позволяя использовать сервер как физический музыкальный центр с выводом звука на звуковую карту или ЦАП (DAC). |
| **Серверная очередь воспроизведения (PlayQueue)** | **Поддерживается** (`PlayQueueController.kt`, `LiveQueueController.kt`) | **Поддерживается** (`playqueue.go`, сохранение очереди в SQLite) | Navidrome поддерживает стандартный `savePlayQueue` и расширение OpenSubsonic `indexBasedQueue` (`getPlayQueueByIndex`, `savePlayQueueByIndex`). |
| **Умная волна рекомендаций («Моя волна»)** | **Поддерживается эксклюзивно в нашем форке** (ветка `feature/kord-api`, `/rest/kord/vibe/next`) | **Не поддерживается** (есть только базовый `getRandomSongs` и акустический `sonicSimilarity`) | Наш форк реализует алгоритм потокового радио на основе настроения, характера и языка (3 оси фильтрации), интегрированный с системой дизлайков (`/rest/kord/dislike`). |

## 3. Сетевые протоколы и периферийные сервисы

| Протокол / Сервис | Airsonic Advanced | Navidrome | Особенности реализации |
|---|---|---|---|
| **DLNA / UPnP Media Server** | **Встроен** (`CustomContentDirectory.java`, настройки в `DLNASettingsController.kt`) | **Отсутствует** (требуется внешний шлюз, например `upmpdcli`) | Airsonic позволяет Smart TV, медиаплеерам и сетевым ресиверам воспроизводить музыку по локальной сети без установки сторонних приложений. |
| **Sonos Music API (SMAPI)** | **Встроен** (`sonoslink`, поддержка SOAP-эндпоинтов Sonos) | **Отсутствует** (требуется отдельный мост `bonob`) | Колонки Sonos могут напрямую подключаться к Airsonic как к официальному облачному сервису. Для Navidrome сообщество запускает отдельный Docker-контейнер Bonob. |
| **Google Cast (Chromecast)** | **Поддерживается** (документировано в `CHROMECAST.md`, веб-сендер) | **Поддерживается в веб-интерфейсе** (через Chrome Cast API браузера) | Обе системы позволяют транслировать аудиопоток на устройства Chromecast. |
| **Jellyfin Client API (`/jellyfin`)** | **Отсутствует** | **Встроен** (`server/jellyfin/`) | Navidrome эмулирует нативное API Jellyfin! Это позволяет подключать популярные современные клиенты экосистемы Jellyfin: **Finamp**, **Streamyfin**, **Jellyfin Mobile**, **Jellycli**. |

## 4. Плейлисты: Статические, умные и совместные

| Возможность | Airsonic Advanced | Navidrome | Особенности реализации |
|---|---|---|---|
| **Статические плейлисты (M3U, M3U8)** | **Поддерживается** (`PlaylistImportController.kt`, `PlaylistExportController.kt`) | **Поддерживается** (автоматический скан папок с плейлистами, экспорт через API) | Оба сервера умеют читать и генерировать M3U/M3U8 списки воспроизведения. |
| **Умные динамические плейлисты (Smart Playlists)** | **Отсутствует** (только базовые случайные подборки и выборки по жанру/году) | **Полноценный встроенный движок** (`.nsp` файлы, модуль `model/criteria/`) | **Ключевое преимущество Navidrome:** мощнейший язык запросов на базе JSON/YAML AST. Поддерживает логические операторы (`all`, `any`, `none`), десятки полей (`bpm`, `playCount`, `lastPlayed`, `rating`, `year`, `genre`) и операторы (`contains`, `startsWith`, `inTheLast`, `gt`, `lt`). Вычисляется на лету или в фоне. |
| **Публичные ссылки (Share Links)** | **Поддерживается** (`SharesController.kt`, `/ext/share/*`) | **Поддерживается** (`sharing.go`, `model.Share`, публичный URL с токеном) | Оба проекта позволяют делиться треками или альбомами через временные публичные ссылки с веб-плеером без авторизации. |

## 5. Скробблинг и внешние агенты метаданных

| Сервис / Источник | Airsonic Advanced | Navidrome | Особенности реализации |
|---|---|---|---|
| **Last.fm** | **Поддерживается** (`LastFMScrobbler.java`, скробблинг, Now Playing, получение биографий и похожих исполнителей) | **Поддерживается** (`core/external/lastfm`, скробблинг, биографии, похожие исполнители, топ-треки) | Полная двухсторонняя интеграция скробблинга и выкачивания метаданных. |
| **ListenBrainz** | **Поддерживается** (`ListenBrainzScrobbler.java`) | **Поддерживается** (`core/external/listenbrainz`) | Отправка открытых скробблов в проект MetaBrainz. |
| **MusicBrainz (MBID)** | **Ограниченно** (чтение MBID тегов из файлов) | **Глубокая нативная интеграция** (поля `mbz_artist_id`, `mbz_album_id`, `mbz_track_id`, загрузка обложек из Cover Art Archive) | Navidrome использует MBID как первоклассный базис для Persistent IDs и дедупликации исполнителей. |
| **Spotify** | **Отсутствует** | **Поддерживается** (`core/external/spotify`) | Navidrome может использовать API Spotify как внешнего агента для загрузки фотографий артистов высокого разрешения и дискографий. |
| **Discogs** | **Поддерживается** (поиск обложек в вебе) | **Через плагины** (подсистема WASM-плагинов) | Airsonic имеет встроенный клиент для Discogs; Navidrome делегирует сторонние каталоги плагинам. |
| **Акустический поиск (Sonic Similarity)** | **Отсутствует** | **Поддерживается** (`core/sonic/`, OpenSubsonic расширение `sonicSimilarity`) | Navidrome может подключаться к векторному поисковому серверу Sonic для поиска акустически похожих композиций и построения гладких путей перехода (`findSonicPath`). |
